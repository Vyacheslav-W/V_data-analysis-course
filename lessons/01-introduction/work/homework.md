## H3. Инструменты

Series - столбец таблицы, например "home_outcomes = home_decisions["action_taken"]"; 
DataFrame - таблица с данными, например "home_decisions = pd.read_csv(...)".

nrows - метод позволяющий выбрать количество первых строк для загрузки из таблицы в вывод, например "home_decisions = pd.read_csv(..., nrows=5)" читает только 5 строк; 
head - метод для вывода определённого количества первых строк из уже загруженной таблицы, например "print(home_decisions.head(10))" выводить первые 10 строк загруженной таблицы.

Метод - это функция, которую вызывают со скобками, например "home_outcomes.eq(n_not_accepted).sum()"; 
атрибут - это свойство объекта, к которому обращаются без скобок, например "home_decisions.shape".

Ссылка на документацию и что удалось уточнить: [eq](https://pandas.pydata.org/pandas-docs/version/2.2/reference/api/pandas.Series.eq.html), уточнил параметр `eq`: он используется для проверки равенства значения в скобках со значениями из таблицы. home_outcomes.eq(3) сравнивает каждый код исхода с числом 3. Если нашел то выводит результат True, иначе False.

## H+2. Типы значений — необязательно

Выполнялось: да.
Результаты сравнений и объяснение: в `text_example` столбец `action_taken` прочитан как строки. `eq(1)` сравнивает с числом: все значения False, количество True = 0. `eq("1")` сравнивает со строкой: количество True = 2.
